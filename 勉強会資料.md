# クラウドログ

## AWS
ここでは頻出のサービス、IAM、EC2、S3、Lambdaについてログ表現を学び
余裕があればネットワークログについても学ぶ

AWS上の操作・処理
├── AWS API操作
│     └── AWS CloudTrail
├── EC2／LambdaのOS・アプリケーション出力
│     └── Amazon CloudWatch Logs
├── AWSサービスが発行する状態変更イベント
│     └── Amazon EventBridge
├── S3オブジェクト操作
│     ├── CloudTrail Data Events
│     ├── S3 Server Access Logs
│     └── S3 Event Notifications／EventBridge
└── 認証
	  ├── CloudTrail ConsoleLogin
	  └── CloudTrail APIイベントのuserIdentity


### CloudTrail共通ログの見方
AWSのログの多くはCloudTrailというサービスに格納される
CloudTrailに格納されるログは共通する文法（基底オブジェクトのような）
```
{
	"eventVersion": "1.11",
	"userIdentity": {
		"type": "IAMUser",
		"principalId": "AIDAEXAMPLE",
		"arn": "arn:aws:iam::123456789012:user/example-user",
		"accountId": "123456789012",
		"userName": "example-user",
		"sessionContext": {
			"attributes": {
							"creationDate": "2026-01-01T00:00:00Z",
							"mfaAuthenticated": "true"
				}
			}
		},
	"eventTime": "2026-01-01T00:10:00Z",
	"eventSource": "ec2.amazonaws.com",
	"eventName": "StartInstances",
	"awsRegion": "ap-northeast-1",
	"sourceIPAddress": "192.0.2.10",
	"userAgent": "aws-cli/2.x",
	"requestParameters": {},
	"responseElements": {},
	"requestID": "request-id",
	"eventID": "event-id",
	"readOnly": false,
	"eventType": "AwsApiCall",
	"managementEvent": true,
	"eventCategory": "Management"
}
```

eventTime
  → いつ

userIdentity
  → 誰が、どの資格情報で

eventSource
  → どのAWSサービスに対して

eventName
  → 何のAPI操作を

requestParameters
  → 何を対象として、どの値を指定して

responseElements
  → AWSサービスが何を返したか

errorCode / errorMessage
  → 成功したか、失敗したか

### AWS Lambda
サーバーを利用者が構築・管理することなく、プログラムを実行できるAWSのコンピューティングサービス
利用者は処理内容を記述したコードと実行条件を設定し、実行環境の準備、起動、拡張、停止などはAWS側が管理
イベント発生
    ↓
Lambda関数が呼び出される
    ↓
AWSが実行環境を確保
    ↓
指定されたコードを実行
    ↓
実行結果やログを出力
    ↓
処理終了後、実行環境を停止または再利用

# Lambdaのロール話
C2上のアプリケーションがInvokeFunctionAPIを直接呼び出し、Lambda関数がS3オブジェクトを取得する構成

EC2インスタンス
  └─ EC2インスタンスロールを使用
       ↓ lambda:InvokeFunction
Lambda関数
  └─ Lambda実行ロールを使用
       ↓ s3:GetObject
S3バケット

## LambdaからS3へアクセスするとき
Lambdaサービスが、関数に設定されたLambda実行ロールを引き受ける
```
{
  "eventSource": "s3.amazonaws.com",
  "eventName": "GetObject",
  "userIdentity": {
    "type": "AssumedRole",
    "principalId": "AROALAMBDAEXAMPLE:example-function",
    "arn": "arn:aws:sts::123456789012:assumed-role/LambdaExecutionRole/example-function",
    "accountId": "123456789012",
    "sessionContext": {
      "sessionIssuer": {
        "type": "Role",
        "principalId": "AROALAMBDAEXAMPLE",
        "arn": "arn:aws:iam::123456789012:role/LambdaExecutionRole",
        "userName": "LambdaExecutionRole"
      }
    }
  },
  "requestParameters": {
    "bucketName": "example-bucket",
    "key": "documents/report.pdf"
  }
}
```

EC2インスタンス
  │
  │ インスタンスプロファイル経由で
  │ EC2InvokeLambdaRoleの一時認証情報を取得
  ↓
EC2InvokeLambdaRoleのセッション
  │
  │ lambda:InvokeFunction
  ↓
Lambda関数
  │
  │ LambdaサービスがLambdaExecutionRoleを引き受ける
  ↓
LambdaExecutionRoleのセッション
  │
  │ s3:GetObject
  ↓
S3オブジェクト
